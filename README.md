# Assassin's Creed 1 – Movement Rewrite

A personal/educational project focused on recreating and rewriting the movement system from **Assassin's Creed 1**.

The project is intended for **educational and learning purposes**, focusing on understanding movement systems, player controllers, animation, and game programming techniques.

## Purpose

* Study and recreate classic Assassin's Creed movement mechanics.
* Experiment with player movement and traversal systems.
* Improve programming and game-development skills.
* Understand how different movement states interact with one another.
